# EZUnity Samples

本目录保存各独立 Package 导入到 EZUnity 开发工程中的示例副本，用于直接查看、修改和验证示例。

示例的正式来源是对应 Package 的 `Samples~` 目录。修改本目录中的示例不会自动同步回 Package 仓库；如果修改需要发布，应同步修改对应 Package 的示例内容。

## 使用说明

Package 的功能说明和示例用法请查看对应 Package 的 README。示例版本应与当前使用的 Package 版本保持一致；升级 Package 后，如果示例发生变化，应重新导入对应版本的 Samples。
